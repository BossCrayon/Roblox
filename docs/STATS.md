# Sequence balance tables

All numbers are original gameplay balance, not canon claims. Multipliers are absolute relative to Sequence 9, never compounded. Health/Strength/Intuition/Resistance/regen use t; spirituality uses t^1.5; Agility/Perception use sqrt(t); Sanity uses 1. Digestion starts at 0 and caps at 100 at every sequence.

Perception = Spirit Vision range in studs. Regen = spirituality per second. Resistance is a rating. Values rounded to two decimals. These are max/base stats; current resources belong to player state.
