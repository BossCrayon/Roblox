# Engine checks still required

Cloud tests run real Luau and build the real place, but use fake Roblox engine dependencies for executor tests. Complete these checks in Roblox Studio before describing the game as engine-tested or publishing it publicly.

1. Open `build/Mysteries.rbxlx`, press Play, and confirm the sanctuary, HUD, arenas, practice doors and 18 enemy models appear with no Output errors. Confirm third-person camera bounds, keyboard and touch controls, resizing, journal scrolling and cooldown feedback.
2. Start a server with two players. Confirm each gets an independent loaded session and inventory, one player's casting/equipping cannot change the other's state, owner-only gates and marionettes reject other players, and all combat affects only eligible NPCs.
3. For each pathway drink Sequence 9, use its objective, and confirm only the matching objective awards digestion. Repeat one completion during its cooldown, try early/foreign/skipped potions, and confirm no items are consumed. Buy the next potion with earned gold and confirm full digestion is required.
4. Test Seer, Marauder and Apprentice 9–7 first. For Seer verify an actual dodged attack awards Clown acting; blocked landings cannot flame-jump; paper substitutes negate one lethal hit. For Marauder verify one loot theft per NPC and cipher archive requirements. For Apprentice verify closed doors actually open and star readings can succeed/fail against server-held omens.
5. Use each Studio mastery stone (session-only mode) to unlock all 18 pathway abilities. Equip retained powers through the journal and exercise every ability. Record requires a witnessed NPC ArcBolt, stolen/recorded powers use the whitelist and charge limits, marionette exchange requires an owned target, and wishes spend credits only when recovery is possible. Historical echoes require a fresh archive read.
6. Check disguise/identity restoration on expiry, death, advancement and stabilization. Disguises use original face masks, identity/color changes and R15 scale profiles. R6 rigs retain their original dimensions. Original voice-profile audio can be bound through SFX hooks; live voice cloning is not implemented. Verify control, parasitism, confusion, sleep, time slow, stasis, burning and payload expiry; stronger NPCs shorten lower-tier debuffs. Test graft acting only after an attack reflects, not merely after casting.
7. Repeatedly teleport and use both ends of a gate. Reject out-of-bounds, occupied, unsupported or obstructed landing points. Confirm legitimate travel is exempted from the horizontal movement guard. Gates and owned summons must disappear on expiry, death and leaving. The movement guard is a basic server check, not a complete movement anti-cheat.
8. Remain in a high-tier arena until sanity hits zero: whispers/exposure should drain it, madness should last 10 seconds, loss of control should kill once, respawning should permit walking to Stabilization, and recovery should cost digestion. Verify spirituality regen delay/combat penalty and resource caps.
9. In an isolated published development place, use an isolated DataStore name and set StudioSessionOnly=false. Enable Studio API access. Save/rejoin and verify pathway, sequence, digestion, acting, sanity, inventory, credits and loadout. Attempt a second session, then shut down the first and verify it can acquire only after release or lease expiry. Check that API denial/load failure kicks rather than overwrites saves.
10. Test crowded combat while watching server/client performance. VFX and highlights are pooled and bounded; NPCs tick at 0.25 seconds rather than per frame. Confirm repeated respawns and player departures do not accumulate models, connections or gates. Tune numbers in data modules based on measured fights; current balance is an initial numerical pass, not a player-tested release balance.

Publishing remains a separate action in Roblox Studio. No place ID, Roblox publishing credential, engine runtime, or publication tool was available to the cloud agent. Do not treat a generated `.rbxlx` as evidence of a published experience.
